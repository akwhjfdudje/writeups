###This is a writeup for the Hack The Box machine 'Hospital'. Initial foothold was very obvious, took some time to get the correct payload, user was a little harder, but root demonstrated a significant problem with automated scripts, although an alternative pathway demonstrates issues with misconfigurations. Also this might be the least windows machine in existence :P###

initial nmap scan shows ports 53,88,135,139,389,443,445,464,593,636,1801,2103,2105,2107,2179,3268,3269,3389,8080 are open (pain)

found two websites, one on port 443, using roundcube webmail

second website, on port 8080 has a file upload, potentially rce

spawned a webshell, using https://raw.githubusercontent.com/flozz/p0wny-shell/master/shell.php

enumerating server, found config.php file containing mysql creds

used creds to obtain user credentials, dead end.

checked /home, found user drwilliams

exploit kernel using gameoverlayfs (although i found another exploit on the machine, and used that instead, would have done the same thing)

got /etc/shadow file

got credentials drwilliams:qwe123!@#

got access to webmail

found conversation between williams and dr brown, discussing ghostscript, an interpreter for postscript

researching payloads in postscript, found one that creates a reverse shell in ps

got reverse shell, and user.txt

found potentially useful creds drbrown:chr!$br0wn

used xfreerdp to rdp to the machine

a script was running that sent keystrokes containing the admin password every few minutes, intercepted the keystrokes

got creds for admin Administrator:Th3B3stH0sp1t4l9786!

rdp'd again, got root.txt

addendum: there is an alternative pathway to root, however it is likely not the intended path, utilising how xampp runs as root continuously, and how that can be exploited by adding a *shell.php file in \xampp\htdocs. I say not intended since when I revisited the box, write access to the directory was blocked
